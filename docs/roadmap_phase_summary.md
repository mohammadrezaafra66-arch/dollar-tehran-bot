**نکته مهم و قطعی:** هیچ مرحله‌ای برای ساخت وب‌اپ نداریم. هرجا بحث پنل لوکال می‌آید، منظور فقط این است که برای سازنده وب‌اپ، قرارداد ورودی/خروجی و نیازمندی اتصال می‌نویسیم. ساخت پنل، UI، API وب‌اپ یا dashboard با ما نیست.
